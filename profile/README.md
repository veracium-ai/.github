# veracium

**Provenance-aware memory for agentic systems.** veracium gives any agent
durable, per-user memory that structurally resists injection and confabulation:
typed graph facts with provenance and supersession-with-history, quarantine of
third-party claims, and an evidence-grounded abstention gate that answers only
from grounded memory — and says "I don't know" rather than guessing.

- 📦 **Install:** `pip install veracium` · [PyPI](https://pypi.org/project/veracium/)
- 🔧 **Code & docs:** [veracium-ai/Veracium](https://github.com/veracium-ai/Veracium)
- 🔌 **MCP server included** — plug memory into any MCP-compatible agent
- 🤝 **Contributing:** [good first issues](https://github.com/veracium-ai/Veracium/issues?q=is%3Aissue+is%3Aopen+label%3Agood-first-issue) · [CONTRIBUTING.md](https://github.com/veracium-ai/Veracium/blob/main/CONTRIBUTING.md)
- 🔒 **Security:** memory poisoning is a vulnerability, not a quality bug — [report privately](https://github.com/veracium-ai/Veracium/security/policy)
